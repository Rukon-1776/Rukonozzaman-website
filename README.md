# Md. Rukonozzaman Rukon | Academic Portfolio

Static portfolio website (one `index.html`, no build step).

## Publish on GitHub Pages
1. Create a repository named `<your-github-username>.github.io`.
2. Upload `index.html`, `README.md` and `.nojekyll`.
3. Open Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-github-username>.github.io/`.

## Editing
All text is in `index.html`. The contact email is the `EMAIL` variable at the bottom of the file.
